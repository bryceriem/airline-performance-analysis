# Streamlit App Documentation

## Overview

The Streamlit app (`streamlit_app.py`) renders both dashboards as an interactive web application connected live to Snowflake. It was initially generated by Snowflake's Snowsight "Export to Streamlit" feature and then significantly modified to fix unsupported chart types, add interactivity, and improve visual quality.

---

## Tech Stack

| Library | Purpose |
|---|---|
| `streamlit` | App framework, layout, tabs, sidebar, native charts |
| `snowflake` (via `st.connection`) | Live Snowflake query execution |
| `pandas` | DataFrame manipulation and pivoting |
| `plotly.graph_objects` | Custom heatmap (Figure 1.2) |
| `plotly.express` | Line, bar, and scatter charts with y-axis control (Figures 1.1, 2.1, 2.2, 2.3) |
| `datetime` | Footer timestamp |

---

## App Structure

```
st.set_page_config        — wide layout, page title
st.title                  — dashboard title
st.connection("snowflake") — Snowflake session

execute_query()           — cached query dispatcher (23h50m TTL)

st.sidebar                — Compare Carriers multiselect + Reset to All button

st.tabs                   — separates Dashboard 1 and Dashboard 2

  Tab 1: Dashboard 1 — Load Factor Efficiency
    Figure 1.1 — Load Factor Line Chart
    Figure 1.2 — Load Factor Heatmap

  Tab 2: Dashboard 2 — Departure Reliability
    Figure 2.1 — Reliability Rankings Bar Chart
    Figure 2.2 — Reliability Over Time Line Chart
    Figure 2.3 — Reliability vs. Size Scatter Chart

st.markdown footer        — load timestamp
```

## Interactive Elements

### 1. Compare Carriers
A `st.multiselect` in the sidebar that filters which carriers are displayed across all 5 charts. All 9 carriers are always fetched from Snowflake — filtering happens at the DataFrame level after the query returns. When a selection is active, each chart renders only the selected carriers, and an **Industry Average** benchmark (computed from all 9) is overlaid for context. A **Reset to All** button appears when a selection is active; it clears the selection via an `on_click` callback (`st.session_state["comparison_selection"] = []`), which avoids the Streamlit restriction against modifying a widget's session state key after instantiation. The session state key is pre-initialized with `if key not in st.session_state` before the widget renders to prevent the `default=` conflict.

The benchmark is implemented differently per chart type:
- **Line charts (1.1, 2.2):** `fig.add_scatter()` adds a grey dashed line for the per-year average across all 9 carriers
- **Heatmap (1.2):** an `"Industry Avg"` row is computed and appended to the pivot DataFrame before rendering
- **Bar chart (2.1):** `fig.add_vline()` draws a grey dashed vertical line at the overall average reliability score, labeled with the value
- **Scatter chart (2.3):** `fig.add_hline()` draws a grey dashed horizontal line at the average reliability score

**What it does:** Leave the multiselect empty to display all 9 carriers. Select any subset — 2, 3, or more — and every chart narrows to only those carriers while the Industry Average benchmark remains visible in every chart as a reference point. The Reset button restores the full 9-carrier view in one click.

**Why it adds analytical value:** Selecting 2–3 carriers enables clean head-to-head comparisons across every figure simultaneously — load factor trajectory, heatmap row, reliability ranking, reliability over time, and scatter position — without the visual noise of the other 6. The always-present Industry Average benchmark prevents the comparison from becoming a vacuum: a user comparing Delta and Southwest can see not just how they compare to each other, but whether both are above or below the 9-carrier average. This is analytically meaningful in both directions — two carriers beating the average tells a different story than two carriers both trailing it.

### 2. Dashboard Tabs
`st.tabs` separates Dashboard 1 (Load Factor Efficiency) and Dashboard 2 (Departure Reliability) into two named tabs at the top of the page. The Compare Carriers control in the sidebar remains shared and applies to both tabs simultaneously.

**What it does:** Keeps both dashboards in a single app while letting users focus on one analytical question at a time. Switching tabs does not reset the carrier selection — any spotlight active in Dashboard 1 persists when navigating to Dashboard 2.

**Why it adds analytical value:** The two dashboards answer structurally different questions — one about capacity efficiency, one about operational reliability. Placing them on the same scrolling page creates visual competition between unrelated charts. Tabs make the separation of analytical intent explicit: the user selects which question they are investigating and interacts with only the relevant charts. Because the carrier selection persists across tabs, a user can spotlight two carriers in Dashboard 1 to compare their load factor histories, then switch to Dashboard 2 to immediately see how those same two carriers compare on reliability — without re-entering the selection.

## Chart Implementation Notes

### Figure 1.1 — Load Factor Line Chart
- **Library:** `plotly.express.line` via `st.plotly_chart`
- **Color:** `color="CARRIER_NAME"` — one line per carrier
- **Hover:** `hovermode="x unified"` — all carrier values shown on hover at a given year
- **Benchmark:** `fig.add_scatter()` — grey dashed Industry Avg line computed as per-year mean across all 9 carriers

### Figure 1.2 — Load Factor Heatmap
- **Library:** `plotly.graph_objects.Heatmap` via `st.plotly_chart`
- **Why Plotly:** Snowflake's native heatgrid chart type is not supported in Streamlit. Plotly's `go.Heatmap` replicates the functionality with color-coded cells and value annotations
- **Data prep:** DataFrame pivoted with `df.pivot(index="CARRIER_NAME", columns="YEAR", values="LOAD_FACTOR_PCT")` before passing to Plotly; an `"Industry Avg"` row appended via `pd.concat`
- **Color scale:** Blues — darker = higher load factor
- **Benchmark:** Industry Avg row always appended at the bottom; carrier rows filtered to selection when comparison is active

### Figure 2.1 — Reliability Rankings Bar Chart
- **Library:** `plotly.express.bar` via `st.plotly_chart`
- **Orientation:** Horizontal so carrier names are readable on the y-axis
- **Color:** Continuous `RdYlGn` scale on `RELIABILITY_SCORE` — red = low, green = high; color bar hidden (`coloraxis_showscale=False`)
- **Cap:** `LEAST(..., 100)` applied in SQL so carriers with reliability > 100% are shown at 100 rather than excluded
- **Benchmark:** `fig.add_vline()` — grey dashed vertical line at the average reliability score across all 9, labeled with the value

### Figure 2.2 — Reliability Over Time Line Chart
- **Library:** `plotly.express.line` via `st.plotly_chart`
- **Why Plotly:** Needed `fig.update_yaxes(range=[90, 120])` to cut the y-axis, which is not possible with `st.line_chart`
- **Y-axis range:** 90–120 — captures the full post-pandemic dip while removing empty whitespace below
- **Benchmark:** `fig.add_scatter()` — grey dashed Industry Avg line computed as per-year mean across all 9 carriers

### Figure 2.3 — Reliability vs. Carrier Size Scatter Chart
- **Library:** `plotly.express.scatter` via `st.plotly_chart`
- **Why Plotly:** Two reasons — needed y-axis cut and the auto-generated `st.scatter_chart` code was grouping by `CARRIER_SIZE` before rendering, which dropped `CARRIER_NAME` and broke the color-by-carrier feature
- **Y-axis range:** 97–104 — zooms into the tight band where all carriers cluster, with margin on each side
- **Color:** `color="CARRIER_NAME"` — one color per carrier
- **Hover:** `hover_name="CARRIER_NAME"` — carrier name shown prominently in tooltip; no on-chart text labels to avoid overlap
- **Marker size:** 14 — large enough to read by color without label text
- **Benchmark:** `fig.add_hline()` — grey dashed horizontal line at the average reliability score across all 9, labeled with the value
